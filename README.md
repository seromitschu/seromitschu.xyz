## 🎢 Neler Var Neler? (Özellikler)

Sitemiz tek bir sayfadan ibaret değil, içinde kaybolabileceğin sihirli "odalar" var:

*   🏠 **Ana Sayfa:** Kimim ben, neler yapıyorum? Kısa ve öz bir tanışma faslı.
*   📝 **Blog:** Markdown tabanlı, kendi yazdığım yazıları paylaştığım tonton bir köşe.
*   🎵 **Müzik Odası:** Spotify & Apple Music entegrasyonu! Şu an ne dinliyorum? Müzik zevkim nasıl? Hepsi burada. 🎧
*   🎮 **Oyun Odası:** Steam Web API destekli! En çok oynadığım oyunlar, seviyem ve başarımlarım. (Evet, çok oyun oynuyorum!) 👾
*   🎬 **Sinema Odası:** İzlediğim film ve dizilerin sergilendiği, patlamış mısırlık arşiv. 🍿
*   🖼️ **Galeri:** Görsel tasarımlarımın ve sevdiğim karelerin olduğu minik sergi. 🎨
*   💻 **Geliştirme Odası:** GitHub REST API ile beslenen canlı repo, yıldız ve commit verileri! 🛠️
*   📖 **Guestbook (Ziyaretçi Defteri):** Supabase (PostgreSQL) destekli! Geldiysen bir selam bırak, duvara yazını yaz! 🖍️
*   ⌘ **Sihirli Komut Paleti (⌘K / Ctrl+K):** İstediğin odaya veya yazıya ışınlanmanı sağlayan arama motoru! 🪄
*   🔔 **Liquid Glass Bildirimler:** URL kopyaladığında veya form yolladığında ekranda "boing!" diye beliren jöle gibi bildirimler. 🍮
*   🧭 **Akıllı Kalp Navbar:** Sayfayı aşağı kaydırınca küçülüp minik bir kalbe (❤️) dönüşen yaramaz menü çubuğu!

## 🪄 Kurulum (Kendi Bilgisayarında Çalıştır!)

Eğer kodları kurcalamak istersen, işte yapman gerekenler:

```bash
# 1. Projeyi bilgisayarına kopyala
git clone [https://github.com/seromitschu/seromitschu.xyz.git](https://github.com/seromitschu/seromitschu.xyz.git)

# 2. Klasörün içine gir
cd seromitschu.xyz

# 3. Bağımlılıkları (oyuncakları) yükle
npm install

# 4. Ve motoru çalıştır! 🏎️
npm run dev
